# Governance

Fajita is an open-source project created and maintained by [Accomplish Labs](https://accomplishlabs.com).

## Roles

| Role | Responsibility |
| --- | --- |
| **Accomplish Labs** | Creates, owns, maintains, and commercially operates Fajita and Fajita Cloud |
| **Maintainers** | Review contributions, triage issues, cut releases, steward security response |
| **Contributors** | Submit issues, documentation, and code under AGPL-3.0 |

## Decision making

Day-to-day product and engineering decisions for the open-source repository are made by maintainers. Larger direction changes are discussed in GitHub Issues and Discussions before substantial implementation.

Accomplish Labs retains final authority over:

- Trademark and brand use
- Fajita Cloud service policy and operations
- Security response for the hosted service
- Release timing for tagged versions

## Contribution expectations

Contributions follow [CONTRIBUTING.md](./CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md). Pull requests require maintainer review. Destructive or security-sensitive changes may need additional review.

## Relationship to Fajita Cloud

- **Fajita** is the open-source project at [github.com/fajita-io/fajita](https://github.com/fajita-io/fajita).
- **Fajita Cloud** is the managed service at [fajita.io](https://fajita.io).

Both share core monitoring code. Fajita Cloud adds managed operations, billing, and support appropriate to a hosted product.

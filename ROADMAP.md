# Roadmap

This roadmap reflects current priorities. No dates are promised. Items move based on reliability, contributor feedback, and what makes Fajita meaningfully better at uptime monitoring.

## Now

- Open-source launch preparation (documentation, CI, repository polish)
- Self-hosting stability and operator documentation
- Docker Compose and release artifact pipeline
- Security hardening for public repository and fork CI

## Next

- Published container images on GHCR with tagged releases
- Reverse proxy and production Compose reference examples
- Additional notification integration polish
- Stronger status page customization options
- Contributor-requested documentation improvements

## Later

- Optional multi-region worker deployment guidance
- Advanced incident workflow tooling
- Broader ecosystem integrations where demand is clear
- Self-hosted auth evaluation (reduce Clerk friction for operators who need it)

## Not planned as default scope

- Full observability platform / Datadog replacement positioning
- Arbitrary feature parity with every commercial competitor
- Food-themed product terminology in critical workflows

## How to influence the roadmap

Open a [feature request issue](https://github.com/Accomplish-Labs/fajita-io/issues/new?template=feature_request.yml) with the problem you are solving. We prioritize work that improves verification quality, alert signal, self-host operability, and status page trust.

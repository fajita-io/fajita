# Support

## Community support (self-hosted and open source)

Use these channels for the open-source project:

| Channel | Best for |
| --- | --- |
| [GitHub Discussions](https://github.com/fajita-io/fajita/discussions) | Questions, ideas, show-and-tell |
| [Documentation](./docs/README.md) | Installation, configuration, upgrades |
| [GitHub Issues](https://github.com/fajita-io/fajita/issues) | Reproducible bugs and feature requests |
| [Troubleshooting](./docs/self-hosting/TROUBLESHOOTING.md) | Common self-host failures |

Community support is best-effort. Maintainers respond when they can. There is no guaranteed SLA for free self-hosted deployments.

Before opening an issue:

1. Run `npm run selfhost:doctor`
2. Remove secrets from logs (see issue templates)
3. Include Fajita version and deployment mode

## Fajita Cloud support

Customers on [Fajita Cloud](https://fajita.io) receive support through Fajita's managed service channels. See your account or billing portal for contact options.

Cloud support covers the managed service, not arbitrary self-hosted installations unless explicitly contracted.

## Security issues

Report vulnerabilities privately per [SECURITY.md](./SECURITY.md). Do not use public issues for exploitable problems.

## Commercial and trademark questions

Contact [fajita.io/contact](https://fajita.io/contact) with topic **Legal** or **Support** as appropriate.

# Documentation microcopy

Internal. Short strings used across the documentation UI.

**Date:** 2026-07-17

## Principles

Calm, clear, dry where it fits, never cute, never corporate apology. No em
dashes. Aligns with the product voice.

## Strings in use

| Surface | Copy |
| --- | --- |
| Landing hero | Everything you need to monitor, alert, and communicate with confidence. |
| Search trigger | Search documentation |
| Search empty | Type to search the documentation. |
| Search no result | No matches. Try a different word or check the troubleshooting guides. |
| Feedback question | Was this page helpful? |
| Feedback thanks | Thanks. This helps us improve the docs. |
| Feedback comment note | Do not include secrets, tokens, or personal data. |
| Deprecated banner | This page describes older behavior. |
| Copy button | Copy / Copied |

## Rules

- One dominant action per surface.
- Errors say what happened and what to do next, and preserve input.
- No secrets in any example placeholder or copied text.

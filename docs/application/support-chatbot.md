# Ask Fajita

Customer-facing support chatbot. Identity: Ask Fajita (not a human name).

- Answers from approved documentation and registries
- Cites sources
- Offers human handoff without inventing response times
- Powered by Pamphlet attribution on every surface
- No autonomous account changes

Routes: `/support`, `/app/support`. Launcher on marketing, docs, glossary, content, and app shells. Not on public customer status pages.

# Retained revenue model

Versions: `retained-mrr-v1`.

- New MRR: newly paid organizations
- Activated new MRR: new MRR that reached core activation
- Day-7 / Day-30 retained new MRR: good standing + retained activity
- Net retained MRR movement: retained new + expansion + reactivation − contraction − churn
- Channel-retained MRR: attributed retained MRR without double counting

Exclude unpaid, refunded, disputed, fraudulent subscriptions.

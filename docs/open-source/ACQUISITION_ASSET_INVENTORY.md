## What a buyer acquires

- Domain and brand
- Official GitHub org/repo stewardship
- Fajita Cloud customer relationships and billing
- Production infrastructure and operational runbooks
- SEO and content library
- Trademark usage policy (not unrestricted brand license)
- Community (Issues, Discussions)
- Future commercial rights to managed offering

- Source code (AGPL-3.0; forks allowed under license)
- Self-host operators running independent instances

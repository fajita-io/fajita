## Submission blurb (reuse)

**Name:** Fajita

**Short:** Open-source uptime monitoring that verifies failures before waking you up.

**Long:** Fajita monitors websites, APIs, SSL certificates, and cron/heartbeat jobs. It re-checks failures before opening incidents and sending alerts. Includes status pages, Slack, Discord, webhooks, and email. Self-host with Docker Compose (AGPL-3.0) or use Fajita Cloud for managed operation.
